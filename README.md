# EDPay Magento 2 / Adobe Commerce Module

[![Magento Version](https://img.shields.io/badge/Magento-2.4.x-orange.svg)](https://magento.com)
[![PHP Version](https://img.shields.io/badge/PHP-8.1%20%7C%208.2-blue.svg)](https://php.net)
[![Status](https://img.shields.io/badge/Status-Coming%20Soon-amber.svg)](https://edpay.co.mz)

Módulo oficial de pagamentos da **EDPay** para lojas virtuais **Magento 2 / Adobe Commerce**.

---

## Funcionalidades

- Integração nativa com o checkout do Magento 2 via Payment Provider Gateway.
- Redirecionamento seguro para Checkout Alojado da EDPay com todos os canais de Moçambique (M-Pesa, e-Mola, Cartões Visa/Mastercard, Apple Pay, Google Pay).
- Reconciliação em segundo plano através de webhooks assinados com HMAC SHA-256.
- Compatibilidade com multi-loja e multi-moeda.

---

## Condições Comerciais

- Tarifa unificada de 6,00% em Meticais (MZN).
- Liquidação bancária direta para a conta do comerciante de 2 a 7 dias úteis.
